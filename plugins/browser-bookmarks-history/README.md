# 书签与历史记录搜索

搜索 Chrome / Edge 浏览器的书签与历史记录，支持便携版浏览器。

作者：ScottLim

## 指令

- `书签` — 搜索全部书签 + 历史记录
- `历史记录` — 仅搜索历史记录
- `chrome书签` — 仅搜索 Chrome 书签
- `chrome历史记录` — 仅搜索 Chrome 历史记录
- `Edge书签` — 仅搜索 Edge 书签
- `Edge历史记录` — 仅搜索 Edge 历史记录
- 主窗口直接输入 — 全局联想搜索
- `书签设置` — 配置便携版 Data 目录

## 特性

- 书签条目带 ⭐ 标识，历史记录条目带 🕘 标识
- 支持便携版 Chrome / Edge 的 User Data 目录配置
